# Defold prototype

Defold editor HTTP server url:

    http://127.0.0.1:$(cat .internal/editor.port)/openapi.json

## Automation

Use the project-local Automation Bridge client with `PYTHONPATH=automation-bridge-python`. Open the running editor with `editor.open_project(".", start_if_needed=False)`, then use `project.build_and_run()` or `project.connect_engine()` and the typed `game` helpers for scene queries, input, frame/state waits, and screenshots. Prefer semantic annotations/state over coordinates and sleeps; call `game.close_engine()` only when intentionally stopping an engine your script owns.

## Blender proxy authoring

Treat the existing transparent 2D art as the source of truth and author simplified shadow/physics proxies in Blender; do not generate geometry from image pixels. Existing prototype assets live in `assets/proxies/shadow_proxies.blend`; use one asset-specific blend file for new or parallel work so agents cannot overwrite one another. Prefer the persistent Blender MCP session for serial interactive work and isolated background Blender sessions for parallel assets. Preserve editable source collections, form overlapping parts into watertight unified exterior shells, keep intentional inter-shell occlusion, and preserve the bottom-centre ground contact. Use the argument-driven `validate_asset()` in `tools/render_proxy_validation.py` directly on the live Blender object for the fast edit loop; `--quality fast` checks layout/contact/topology and `review` adds volume and side-shadow images. It creates its own temporary output and returns metrics plus the review directory. Require one connected component per intended shell, zero non-manifold edges, at least the default 90% overall/95% contact art coverage, and sensible volume/side shadows. Use the combined `tools/export_shadow_assets.py` command with `--card`, `--art`, `--surface-output`, and pixel dimensions (see README.md): it validates first, stages the proxy/card exports, and bakes from their exact runtime GLBs before replacing outputs. It requires one slot named exactly `proxy`; card coordinates come from exported transforms and UVs, never hand-entered offsets. For an existing export, `tools/bake_proxy_surface_maps.py` accepts `--proxy-glb` and `--card-glb` only. Keep the authored card at its final runtime transform; the validator no longer moves it. Run `tools/test_shadow_baking.py` through Blender after changes to this pipeline. Use Defold's F2 translucent proxy view occasionally to verify that the offline validator still matches runtime transforms, not for every mesh edit. Do not put WIP artifacts in the project.
